# Robert Weather Center V8 Ultimate

A V8 a tabletre optimalizált prémium kiadás.

## Újdonságok

- V8 Ultimate fejléc és TABLET PRO jelzés
- nagyobb beltéri hőmérséklet
- finom lebegő időjárásikon
- erősebb, élesebb panelkontraszt
- dinamikusabb nappal / naplemente / éjszaka háttér
- belépési animációk
- gyorsabb, 2 perces frissítés
- továbbra is Netatmo + Open-Meteo + Windy

## Telepítés

1. Csomagold ki a ZIP-et.
2. Töltsd fel a teljes tartalmat a GitHub repository gyökerébe.
3. Engedd a meglévő fájlok felülírását.
4. Commit changes.
5. Várd meg a Cloudflare zöld deploymentet.
6. Frissíts Ctrl + F5-tel, a tableten pedig töltsd újra a Fully Browser oldalt.
