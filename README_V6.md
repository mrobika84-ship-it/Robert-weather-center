# Robert Weather Center V6 Ultimate

Moduláris Cloudflare Pages dashboard Netatmo, Open-Meteo és Windy adatokkal.

## Könyvtárak

- `css/` – különálló stílusmodulok
- `components/` – különálló JavaScript komponensek
- `functions/` – Cloudflare Pages Functions
- `assets/backgrounds/` – háttérképek
- `assets/icons/` – saját ikonok helye

## Feltöltés

1. Csomagold ki a ZIP-et.
2. Töltsd fel a teljes tartalmat a GitHub repository gyökerébe.
3. Engedd a meglévő fájlok felülírását.
4. Commit changes.
5. Várd meg a Cloudflare sikeres deploymentet.
6. Frissíts `Ctrl + F5`-tel.

A meglévő Netatmo OAuth, KV és Cloudflare secrets változatlanul használhatók.
